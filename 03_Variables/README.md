# 📘 Variables

What is a Variable?
A variable is a name given to a memory location. It is used to store data that can be changed during the execution of a program.

## Syntax
datatype variableName = value;

## Example:
int a = 1o;

int a;  // **Declaration**

int is the data type
a is the variable name

Memory is allocated based on the type.

a = 10; // **Assignment**

10 is the value assigned to the variable.


int a = 10; //**Initialization** (Declaration + Assignment)

## Points to Remember
Variables focus on memory allocation.

The data type determines how much memory is required and what type of value the variable can store.

Variables allow you to access and manipulate stored data by referring to the variable name, not the memory address.

## Interview Tip:
What happens when you declare a variable?
 Memory is allocated based on the data type, and the variable name is mapped to that memory location.
